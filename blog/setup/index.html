Overview

I asked an AI to be my mentor and plan a 30-day backend API development using Node.js with the best DX (developer experience), this means using modern best practices and working with TypeScript for type safety.

The stack so far is:

  • TypeScript

  • Express

  • Node

  • Zod for runtime validation, that TypeScript isn't able to verify (incoming HTTP Payloads)

Testing will be done with:

  • built-in Node test runner

Disclaimer: While the AI was happy to output lots of code, I structured the project journey and modified the code as I saw fit. I also documented the process in my own words in the form of these articles. So let's do this.

Project Structure

The 30 day project is structured as a single Git repository with package dependencies installed once at the root, but separate Day X folders with separate source files. Example:

  • 30-days-of-node-api-dev/

    • day-1-setup

    • day-2-routing

    • ...

A bit detailed view:

4/9 Install Packages

Unknown Code
1pnpm add express dotenv -D typescript @types/node @types/express tsx

Why we need these:

  • express is the backend framework

  • typescript TS compiler

  • @types/node@types/express Type definitions for the TS Compiler to ensure our code passes all static type checks. VSCode also uses them for type hints and autocomplete.

  • tsx to restart our .ts server when file changes.

  • dotenv for managing environment variables incl. secrets

  • Create day-1-setup/src/config/environment.ts for finer processing env variables.

TypeScript
1/* fileName: day-1-setup/src/config/environment.ts */
2import dotenv from "dotenv";
3import path from "path";
4
5// Load the .env from the current day's folder
6dotenv.config({
7    path: path.resolve(process.cwd(), "day-1-setup/.env"),
8});
9
10// Fallback to port 3000 if not defined
11export const PORT: number = parseInt(process.env.PORT || "3000", 10);

6/9 server.ts

TypeScript
1/* fileName: day-1-setup/src/server.ts */
2import express from "express";
3import { PORT } from "@/config/environment";
4
5const app = express();
6
7// Middleware: Parse JSON request bodies
8app.use(express.json());
9
10// Health check route
11app.get("/api/v1/health", (request, response) => {
12    response.status(200);
13    response.json({
14        status: "ok",
15    });
16});
17
18// Start server on configured port
19app.listen(PORT, () => {
20    console.log(`🚀 server running on http://localhost:${PORT}`);
21});
