Binary Search Trees In JavaScript

By: Abdullah Fatota
Last updated: 11-05-2025

Overview

Binary Search Trees (BSTs) are data structures that enable the following operations:

  • Inserting, either multiple or single elements.
  • Removing, an element.
  • Searching, if an element is in the data stored.
  • Sorting, the data.

All of this in O(n) for the single operation, and O(n²) for n elements, which is slow compared to other data structures that support the same operations.

Due to the speed issue, plain-BSTs are rarely used in real world applications, However the concepts and algorithms behind their operations power more advanced data structures that are fast and useful, namely:

  • Variations of Binary Search Trees (BSTs) like AVL, Red-Black trees allow for efficient searching in O(log n) and sorting in O(n log n).

Another side benefit is

  • you get a sorting algorithm albeit inefficient one without ever writing a sorting algorithm.

General Tree Definition

A Tree is a non-linear recursive data structure, where each Node:

  • contains its own data, and
  • has references to other nodes. i.e. has children nodes of its own.

Non-linear means different paths are taken to access a target node. This is in contrast to linear structures like Arrays, Stacks and Queues where elements are accessed one after the other in one direction.

Tree Types

A Tree's type is defined by the maximum number of children that any node is allowed to have.

A 1-ary Tree allows any node to have at most 1 child. A 2-ary or Binary Tree allows at most 2 children. A 3-ary Tree 3 children and so on.

Binary Tree

The 2 nodes in a Binary Tree are usually called the Left and Right nodes.

Binary Search Tree (BST)

A BST has an additional constraint where:

  • the root node can have any value, but
  • the left node has to be strictly less than its parent node.
  • the right node has to be strictly larger that its parent node

A JavaScript Implementation

This implementation has 2 classes:

  • class Node is the backbone of the data structure, it contains both:

    • the value and
    • crucially left and right node references, giving the data structure its tree and non-linear access property, and recursive definition.

  • class BinarySearchTree

    • implements all the operations (insert, delete, find and traversal) and will enforce the constraints that make this structure a Binary Search Tree.
    • in addition it will contain the root node

class BinarySearchTree

BinarySearchTree.mjs
import { isDefined, isUndefinedOrNull } from "./utils.mjs";
import { Node } from "./Node.mjs";

class BinarySearchTree {
    /* root node */
    _root;

    /* repeatedly insert */
    constructor(...args) {
        args.forEach((val) => this.insertValue(val));
    }

    root() {
        return this._root;
    }

    isRootUnset() {
        return isUndefinedOrNull(this.root());
    }

    /* assuming node is of type Node */
    setRootNode(node) {
        this._root = node;
    }

    insertValue(val) {
        const newNode = new Node(val);

        if (this.isRootUnset()) {
            this.setRootNode(newNode);
            return;
        }

        /* recursive 'helper' insert */
        const recursiveFunction = (currentNode, val) => {
            if (isUndefinedOrNull(currentNode)) return;

            /* if value <  current node, and there is an has an empty left spot then set new node, otherwise unpack */
            if (val < currentNode.value()) {
                if (currentNode.hasEmptyLeftSpot()) {
                    currentNode.setLeftNode(newNode);
                    return;
                }
                recursiveFunction(currentNode.leftNode(), val);
            }

            /* if value <  current node, and there is an has an empty left spot then set new node, otherwise unpack */
            if (val > currentNode.value()) {
                if (currentNode.hasEmptyRightSpot()) {
                    currentNode.setRightNode(newNode);
                    return;
                }
                recursiveFunction(currentNode.rightNode(), val);
            }

            /* end of recursive function */
        };

        /* start recursively from _root node */
        recursiveFunction(this.root(), val);
    }

    /* pre-order traversal, returns array
        visit root node, left tree, right tree
    */
    traversePreOrder() {
        /* recursive traversal */
        const recursiveFunction = (currentNode, array) => {
            /* ends recursion when it reaches either end of left or right tree */
            if (isUndefinedOrNull(currentNode)) return;

            /* visit root */
            array.push(currentNode.value());

            recursiveFunction(currentNode.leftNode(), array);

            recursiveFunction(currentNode.rightNode(), array);

            return array;
        };

        return recursiveFunction(this.root(), []);
    }

    toArray({ "traversal-method": method = "pre-order" } = {}) {
        return this.traversePreOrder();
    }
}

The Insert Algorithm 🔑

}

insert is effectively the bacbkone of constructing the Binary Search Tree in memory. The algorithm is the following:

  1. Start from the root node
  2. check if the root node has been set, if not then set it,
  3. if the root node is set, check if the value-to-be-inserted is lower then root node,
  4. if value-to-be-inserted is lower then root node, we know the value will be inserted somewhere in the left subtree
  5. check if the left spot is empty
  6. if the left spot is empty, set the new node there
  7. if the left spot is not empty, start recursively from Step 4.

The same steps are to be followed if the value-to-be-inserted is greater than the current node:

  1. check if the right spot is empty,
  2. if yes, set the new node there,
  3. if not recursively start from that right node, and go left or right based on comparing the value inside

Traversal is an an algorithm, a systematic way of visiting every node in the tree.

That is if you were given the root reference of a tree, how would you write an algorithm to visit each node.

There are 3 base traversal methods:

  1. Preorder
  2. Inorder
  3. Postorder

Strictly you don't have return anything from the traversal method, as simply visiting each node will suffice. However for my traversal methods I chose to return all elements I traversed in an array.

For Preorder the following recursive algorithm is used:

  1. Visit the node
  2. Visit the left subtree
  3. Visit the right subtree
