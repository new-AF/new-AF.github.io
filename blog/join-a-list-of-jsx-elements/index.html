Join A List of JSX Elements

Abdullah Fatota
Updated: 4-7-2025

Task

I want to modify my jsx: <Footer/> from first photo to second:

That is:

  1. All elements should be prefixed with , except the 2 last elements.

  2. Standalone element & is inserted before the last element. All of this is done to improve readability and user experience.

Solution

Delegate the behavior across both js: RegularList and jsx: ItemComponent components as following:

  1. jsx: <ItemComponent suffix={...} .../> will handle internal item suffixing during item construction. js: <RegularList .../> will pass it jsx: suffix

  2. jsx: <RegularList itemComponent={...} join={true or false} joinMiddleSymbol = ",", joinEndSymbol = "&", .../> Prop jsx: join switches joining behavior on or off.

1. ItemComponent

jsx: <ItemComponent suffix={...} .../>

Each user will decide how suffix is handled (or not) when then pass their <ItemComponent .../>

2. RegularList/FlexList

jsx: <RegularList itemComponent={...} join={true or false} .../>

jsx: FlexList is a thin wrapper around jsx: RegularList which is a React List Design Pattern to (custom) render a list

FlexList.jsx
export const FlexList = ({ className, ...rest }) => (
    <RegularList
        className={mergeClassNames(...)}
        {...rest}
    />
);
RegularList.jsx
/* markLines: 2,3,4,5-10 */

import { Fragment } from "react";
import { isDefined, mergeClassNames } from "../../utils";
import { isValidElement } from "react";

export const RegularList = ({
    array: arrayOriginal,
    children,

    vertical,
    join = false,
    joinMiddleSymbol = ",",
    joinEndSymbol = "&",
    keyName = "singleItem",

    /* default <ItemComponent/> if not passed */
    itemComponent = ({ suffix, ...props }) => {
        const item = props[keyName];
        return isValidElement(item) || Array.isArray(item) ? (
            item
        ) : (
            <div>
                {item}
                {join && joinMiddleSymbol}
            </div>
        );
    },

    className: containerClassName,
    classes = {
        container: mergeClassNames(
            containerClassName ?? false,
            vertical === true ? "flex-col" : false,
        ),
    },
}) => {
    const possibleArray = arrayOriginal || children;
    const array = Array.isArray(possibleArray)
        ? possibleArray
        : [possibleArray];
    const ItemComponent = itemComponent;

    const elements = array.map((singleItem, index, arrayRef) => {
        const key = "item-" + index;
        const props = { [keyName]: singleItem };

        const last = index + 1 === arrayRef.length;
        const beforeLast = index + 1 === arrayRef.length - 1;

        /* <ItemComponent key={key} suffix={joinMiddleSymbol}  {...props} /> */
        if (join && last === false && beforeLast === false) {
            props["suffix"] = joinMiddleSymbol;
        }
        return join && beforeLast ? (
            <Fragment key={key}>
                <ItemComponent key={key} {...props} />
                <span>{joinEndSymbol}</span>
            </Fragment>
        ) : (
            <ItemComponent key={key} {...props} />
        );
    });

    return <ul className={classes.container}>{elements}</ul>;
};

  • If join is true and the item is not the last two: not last, nor before last, then the item will be rendered with suffix.

  • If join is true, and the item is before last, then jsx: RegularList will also render the standalone & element as jsx: Fragment.

jsx
<ItemComponent key={key} suffix={joinMiddleSymbol} {...props} />

jsx
<Fragment key={key}>
    <ItemComponent key={key} {...props} />
    <span>{joinEndSymbol}</span>
</Fragment>

Conclusion

We modified a RegularList to properly delimit a list. This is done by implementing join mode, and letting each ItemComponent handle its own suffix. This renders a list with improved user experience, clarity and readability.
