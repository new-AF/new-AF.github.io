Join A List of JSX Elements

Abdullah Fatota
Updated: 4-7-2025

Task

I want to modify my jsx: <Footer/> from first photo to second:

That is:

  1. All elements should be prefixed with , except the 2 last elements.

  2. Standalone element & is inserted before the last element. All of this is done to improve readability and user experience.

Solution

Delegate the behavior across both js: RegularList and jsx: ItemComponent components as following:

  1. jsx: <ItemComponent suffix={...} .../> will handle internal item suffixing during item construction. js: <RegularList .../> will pass it jsx: suffix

  2. jsx: <RegularList itemComponent={...} join={true or false} joinMiddleSymbol = ",", joinEndSymbol = "&", .../> Prop jsx: join switches joining behavior on or off.

1. ItemComponent

jsx: <ItemComponent suffix={...} .../>

Each user will decide how suffix is handled (or not) when then pass their <ItemComponent .../>

2. RegularList/FlexList

jsx: <RegularList itemComponent={...} join={true or false} .../>

jsx: FlexList is a thin wrapper around jsx: RegularList which is a React List Design Pattern to (custom) render a list

JSX
1/* fileName: FlexList.jsx */
2export const FlexList = ({ className, ...rest }) => (
3    <RegularList
4        className={mergeClassNames(...)}
5        {...rest}
6    />
7);
JSX
1/* fileName: RegularList.jsx */
2/* markLines: 2,3,4,5-10 */
3
4import { Fragment } from "react";
5import { isDefined, mergeClassNames } from "../../utils";
6import { isValidElement } from "react";
7
8export const RegularList = ({
9    array: arrayOriginal,
10    children,
11
12    vertical,
13    join = false,
14    joinMiddleSymbol = ",",
15    joinEndSymbol = "&",
16    keyName = "singleItem",
17
18    /* default <ItemComponent/> if not passed */
19    itemComponent = ({ suffix, ...props }) => {
20        const item = props[keyName];
21        return isValidElement(item) || Array.isArray(item) ? (
22            item
23        ) : (
24            <div>
25                {item}
26                {join && joinMiddleSymbol}
27            </div>
28        );
29    },
30
31    className: containerClassName,
32    classes = {
33        container: mergeClassNames(
34            containerClassName ?? false,
35            vertical === true ? "flex-col" : false,
36        ),
37    },
38}) => {
39    const possibleArray = arrayOriginal || children;
40    const array = Array.isArray(possibleArray)
41        ? possibleArray
42        : [possibleArray];
43    const ItemComponent = itemComponent;
44
45    const elements = array.map((singleItem, index, arrayRef) => {
46        const key = "item-" + index;
47        const props = { [keyName]: singleItem };
48
49        const last = index + 1 === arrayRef.length;
50        const beforeLast = index + 1 === arrayRef.length - 1;
51
52        /* <ItemComponent key={key} suffix={joinMiddleSymbol}  {...props} /> */
53        if (join && last === false && beforeLast === false) {
54            props["suffix"] = joinMiddleSymbol;
55        }
56        return join && beforeLast ? (
57            <Fragment key={key}>
58                <ItemComponent key={key} {...props} />
59                <span>{joinEndSymbol}</span>
60            </Fragment>
61        ) : (
62            <ItemComponent key={key} {...props} />
63        );
64    });
65
66    return <ul className={classes.container}>{elements}</ul>;
67};

  • If join is true and the item is not the last two: not last, nor before last, then the item will be rendered with suffix.

  • If join is true, and the item is before last, then jsx: RegularList will also render the standalone & element as jsx: Fragment.

1<ItemComponent key={key} suffix={joinMiddleSymbol} {...props} />
JSX
1<Fragment key={key}>
2    <ItemComponent key={key} {...props} />
3    <span>{joinEndSymbol}</span>
4</Fragment>

Conclusion

We modified a RegularList to properly delimit a list. This is done by implementing join mode, and letting each ItemComponent handle its own suffix. This renders a list with improved user experience, clarity and readability.
