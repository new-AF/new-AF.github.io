Routing & Controllers

Abdullah Fatota
Updated: 12-8-2025

Objectives

Today we'll create a backend service that will allow us to:

  • retrieve all users stored in our 'database', as JSON array of objects.

  • retrieve a specific user's information

Definitions

But first let's clear a few definitions for:

  • URL

  • Endpoint

  • Router

  • Controller

URL

URL is an absolute locator/address that uniquely identifies a resource/something that can be accessed over the web. Example:

  • http://localhost (this is your local machine)

  • http://localhost:3000/api/v1/users (Users endpoint handling requests)

Endpoint

Endpoint is a part of the URL that's designated/meant to have requests sent to it, and for it to perform some work (by the Controller underneath) and come back with a response. It consists of 2 parts:

  1. the relative path and

  2. the HTTP request type (Method).

Example:

  • GET on /api/v1/users is supposed to send us back an array of all users stored in our backend.

  • POST on /api/v1/users should allows us to create new users and store them.

Endpoints need the Controllers to do the actual useful work, without Controllers Endpoints don't do anything.

Router

Router is the mapping from the Endpoint to the Controller. Example:

  • userRouter.get("/", getAllUsers)

  • userRouter.get("/:id", getUserById)

Controller

Controller is the actual code/function/business logic that processes the HTTP request and sends back a response, often in the form of JSON data. They are central to backend development. Example:

  • function getAllUsers

  • function getUserById

Users Endpoint

Now onto the real task obtaining data about stored users.

Controller

To simulate a database we'll create a simple array of objects representing users, inside the users controller.

TypeScript
1/* fileName: src/controllers/user.controller.ts */
2import { Request, Response } from "express";
3
4const users = [
5    { id: 1, name: "Alice", email: "alice@example.com" },
6    { id: 2, name: "Bob", email: "bob@example.com" },
7];
8
9// GET /users
10export const getAllUsers = (_request: Request, response: Response) => {
11    response.status(200);
12    response.json(users);
13};
14
15const searchUsers = (userId: Number) => {
16    // Search users 'database', returns first matching object, or `undefined` if none are found
17    const result = users.find((user) => userId === user.id);
18
19    if (result === undefined) return { success: false };
20
21    return { success: true, user: result };
22};
23
24// GET /users/:id
25export const getUserById = (request: Request, response: Response) => {
26    const userIdParam = request.params.id;
27    const userId = Number(userIdParam);
28
29    const { success, user } = searchUsers(userId);
30    if (!success) {
31        response.status(404);
32        response.json({
33            error: `User with id ${userId} not found`,
34        });
35        return;
36    }
37
38    response.status(200);
39    response.json(user);
40};
