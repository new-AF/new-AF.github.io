I Migrated to Linux

Abdullah Fatota
Updated: 30 September 2026

TLDR;

I installed Debian on my laptop, but kept Windows intact (Dual Boot). To replicate my setup:

  • Download Debian (13.7 Trixie, GNOME x64)

  • Download Rufus (Windows-only)

  • Make a bootable USB

  • If you don't have free space: Download EaseUS Parition Manager (not sponsored) and shrink your existing big Windows partition.

  • Reboot PC, and boot from USB (for ASUS laptops press ESC)

  • Choose Live Desktop option. Once loaded launch Debian Installer

The Partitions step is the most important, it either will make or break your entire setup (and possibly files on your NVMe/SSD/HDD):

  • Select Manual partitioning

  • Edit the Free Space, or the patition that you don't need, where you'll install Debian:
  • Content -> Format (warning: this will erase all data on the partition)
  • File System -> ext4
  • Mount Point -> /

Click OK to go back to the partitions table.

  • Edit the EFI Partition (100MB FAT32) :
  • Content -> Keep (if not selected by default)
  • Mount Point -> /mnt/efi
  • Flags -> tick boot

Click Next and ignore the warning, and Voila you can continue the rest of the installer.

Complete the rest of the steps with the Installer.

Installation

  • I'm booting from USB, having made a bootable stick with Rufus
  • I have Windows as primary OS.

Here's what I modified:

  • I shrank the the C:\ volume partition to make a free space for Debian. I used EaseUS Parition Manager - not sponsored, because the Windows Disk Management utility is unable to move some unmmoved files which gives you less free space for the new partition, EaseUS restarts Windows and moves those files at boot time. I will mount the new partition as /

Here's the crucial step:

  • I won't modify the EFI Partition: THe 100MB FAT32 that Windows created and contains its boot files. Debian will add its folders there to make my PC able to boot both Windows and Debian. I will mount it at installation to /mnt/boot

  • Swap will be a swap file inside / that we'll later create.

Setting partitions

This is perhaps the most crucial step: What to do with our SSD.

I want to keep Windows as is, but also install Debian on same SSD and boot into it. So we choose Manual partioning

  • We select the free space we created after shrinking Windows partition,
  • then click Edit,
  • choose filesystem as ext4,
  • tick format option,
  • and finally set mount location as /

Confession: Below images are older ones from my previous attempts installing Debian. You'll notice the Debian partion is small ~17GB while Windows is ~400GB. This is because the built-in Windows Shrink space utility inside Disk Management is bad at shrinking the Windows partition because of some unmmovable files, I used later EaseUS Partition Manager (not sponsored) and increased the free space to ~93GB which I then installed Debian for the 3rd time.

Finally and crucially we have to use the EFI partition, it currently has the Windows boot manager but it also must boot Debian and the Linux kernel, so we select first, then click Edit.

We don't format it.

  • We select keep option,
  • then set mount location as /mnt/boot,
  • and finally tick the boot checkbox.

We click OK, then Next.

We get a warning that an EFI Partition must be atleast 300MB in size, as opposed what Windows created as 100MB, but that's fine, we simply click OK, then Next.

Phew, we finished the most difficult step, from here it's all easy.
