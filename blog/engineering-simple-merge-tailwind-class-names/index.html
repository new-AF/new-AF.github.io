Engineering simple-merge-tailwind-class-names

Abdullah Fatota
Updated: 12 July 2026

Overview

This package is a thin wrapper around twMerge and another package of mine: simple-merge-class-names. It provides stricter run-time validation of arguments than twMerge.

It only accepts:

  • Valid strings

  • undefined

  • null

  • false

Valid strings are either the empty string ("") or a string that is not fully whitespace (e.g. "px-4").

Anything else will be ignored and cause a warning to be logged to the Developer Console.

Valid arguments (no warnings)

  1. Valid strings as either:

    • Empty string "",

    • Strings that are not fully whitespace(e.g. px-4, flex, etc.). If there's some whitespace it's not a problem and it will be trimmed without any warnings.

  2. null

  3. undefined

  4. false

Invalid arguments (console warnings)

  • Fully whitespace strings

  • Numbers

  • Objects

  • Arrays

  • true

  • Anything else

Currently there's no way to turn off warnings for invalid arguments

Who needs this package

In 99% of cases you will be fine with twMerge and its validation behavior.

However,

  • If you don't want to be passing invalid arguments to twMerge and want to be warned when that happens,

  • You like the descriptive function name better mergeTailwindClassNames vs twMerge

Then this is the package for you.

The architecture

I used a functional programming approach to build the core package simple-merge-class-names

  1. I map over all user inputs, and classify each one into a one of 3 types ClassifiedClassName, ClassifiedIgnore, or ClassifiedInvalidWarn

  2. For the invalid arguments, they'll be either warned about, have debugger breakpoint if one is active, or do nothing, depending on the provided onClassifiedInvalid function

  3. For the valid arguments, I extract the valid string, and join them

TypeScript
1const mergeClassNamesCore = (
2    values: UserArgument[],
3    onClassifiedInvalid?: ClassifiedInvalidFunction,
4) => {
5    // classify arguments
6    const classified = values.map(classify);
7
8    // optional call invalid arguments handlers: warn and/or activate debugger
9    if (onClassifiedInvalid) {
10        getInvalid(classified).forEach(onClassifiedInvalid);
11    }
12
13    // valid strings only
14    const classNames: string[] = getClassNames(classified).map(
15        ({ value }) => value,
16    );
17
18    const finalClassName = classNames.join(" ");
19    return finalClassName;
20};
TypeScript
1export type ClassifiedIgnore = {
2    status: "ignore";
3    value: unknown;
4};
5
6export type ClassifiedInvalidWarn = {
7    status: "invalid";
8    value: unknown;
9    reason: ClassifiedInvalidReason;
10};
11
12export enum ClassifiedInvalidReason {
13    NotAString,
14    EmptyString,
15    Whitespace,
16}
17
18export type Classified =
19    | ClassifiedClassName // valid string
20    | ClassifiedIgnore // undefined, null, "", or false
21    | ClassifiedInvalidWarn; // Objects, arrays, numbers, `true`, etc
